# linear-regression-study-hours
This project builds a linear regression model to predict exam scores based on hours studied. It includes data visualization, train/test splitting, model training, evaluation (R², MSE), regression line plotting, and residual analysis.

Language: 
- Python

## Skills Used
- Python programming
- Data analysis with Pandas
- Data visualization with Matplotlib
- Machine learning with Scikit‑learn
- Train/test splitting
- Model evaluation (R², MSE)
- Regression line and residual analysis

## Important: 
- To run: Clone the repository:
  - git clone https://github.com/rudramp0751/linear-regression-study-hours.git
- Make sure to install the required Python libraries:
   - pip install pandas matplotlib scikit-learn
 - Run the study_hours_linearRegression.py file

## Results
- The regression model learned a positive relationship between hours studied and exam scores.
- The regression line shows that scores increase steadily as study time increases.
- Evaluation metrics:
  - R² Score: Shows how well the model fits the data. Score: 1
  - Mean Squared Error (MSE): Measures average prediction error. Score: 0
- The residual plot shows that the errors are very minimal. There are no unusual patterns that appear, showing that the linear model is the best for this set.
